## 📌 Overview

The **AI Product Recommendation System** is a Deep Learning-based web application that recommends products to customers using their purchase history and behavioral patterns. The project combines an Artificial Neural Network (ANN) model with a modern web interface to deliver personalized product recommendations and customer analytics.
